# CareerFlow

A local, beginner-friendly job fit checker and outreach helper. Paste a job description to compare it with a starter profile based on AI/ML, computer vision, Python, and robotics data experience. CareerFlow shows keyword overlap, prepares a role-specific email addressed to the contact you provide, and saves checked opportunities in the current browser.

## Run it

Open `index.html` in a browser. No install, account, or API key is needed. Job descriptions and the saved pipeline stay in browser local storage.

## Current limits

- The job link is saved for reference; the page does not fetch or scrape its contents. Paste the description to check it.
- The fit indicator is a keyword overlap estimate, not a prediction of hiring success.
- Each saved opportunity gets its own email draft link. The draft opens in the user's configured mail app and can be addressed to the contact email provided. It does not send the message or attach a resume.
- The page does not search job boards on a schedule. Scheduled checks and sending would need a backend, permitted job data sources, and an email provider connection.

## Before applying

Read the full listing, verify the role and contact, review the generated message, and attach the resume version that fits. Avoid scraping or automating activity on platforms whose terms prohibit it.
